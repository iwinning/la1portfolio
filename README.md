# Andre's Portfolio

Personal portfolio for the DA558A university course. This repository preserves
the Lab 1 HTML and CSS portfolio as the starting point for Lab 2.
Lab 2 functionality has not been implemented.

## View the portfolio

Open `index.html` in a web browser. No installation or build step is required.
You can also use VS Code's Live Server extension if it is already installed.

## Project files

- `index.html`: portfolio content and contact form.
- `style.css`: desktop and mobile styles.
- `images/`: portfolio photographs.
- `feedback.html`: existing empty placeholder.

The contact form uses the visitor's email application through a `mailto:` link;
there is no backend service.

## Development

Keep the Lab 1 portfolio and design intact while completing future coursework.
Review `git status` and staged changes before committing. Keep passwords, API
keys, tokens, and private files out of the repository. `.gitignore` excludes
common local configuration, credential files, dependencies, and generated output.

The portfolio includes personal photographs and a contact email address.
Review these before making the repository public.
